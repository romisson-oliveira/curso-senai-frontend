### Exercício 01: Exibir mensagem para o dev

1. Crie um projeto com nome de aula-02;
2. Crie um pasta 'ex-001' e dentro crie um arquivo `.html` de índice inicial e crie a tag `<script>` e adicione a mensagem `Olá, dev! Estou aprendendo lógica com Javascript no curso front end Senai` para o desenvolvedor;
3. Rode a aplicação em uma porta do navegador local;
4. Abra o _DevTools_ (F12) e verifique se mensagem chegou.

### Exercícios 03:

A partir do **código** Javascript abaixo, tente adivinhar qual o resultado final exibido no console:

```javascript
// Código Javascript
let garrafas = 5;

let preco = 2;

let total = garrafas * preco;

garrafas = 10;

total = garrafas * preco;

console.log(total); // Qual valor aparecerá aqui?
```
