A aula hoje foi muito legal. Conversamos sobre a história da web e entendemos como criar nossos elementos html.

O Hypertext Markup Language (HTML) é utilizado para dá estruturas aos documentos. Não é uma linguagem de programação pois não realiza processamento de dados, isto é, não faz cálculos complexos nem tampouco utiliza estrutura da dados, como condicionais ou laços de repetição.
