## 🎯 UC04: CSS Inline

_Nesta aula tivemos que trabalhar com css inline_

### Enunciado

1. Crie estrutura `HTML5` no seu arquivo na sua pasta de projetos desta uc:
    - `[nome]-css/aula01/inline.html`
2. Crie um título `h1`;
3. Crie seis parágrafos com `lorem ipsum` dentro deles;
4. Mude a cor de todos os elementos usando **css inline**:
    - **Atributo:** use o atributo `style` dentro da tag de abertura do elemento `html`:
        - `style="color: blue`
