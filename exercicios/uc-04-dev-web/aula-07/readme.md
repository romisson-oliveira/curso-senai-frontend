# UC04: Desenvolvimento Web
## 🕹️ Lista de Exercícios — Aula 07 (Display e Icon)

> **Atenção:** Crie a pasta `aula-07-display` e os arquivos `horizontal-nav.html`, `btn-icon.html`, `lab-direta.html` e `style.css`. Use apenas as propriedades de tamanho, cores, fontes, ícones e a propriedade `display`.

#### 🛒 Exercício 1: A Barra de Navegação Horizontal
Você recebeu a tarefa de criar o menu superior de uma loja virtual. No HTML, você estruturou esse menu utilizando uma lista desordenada e colocou links dentro de cada item. 

Por padrão, o navegador listou os itens um abaixo do outro seguindo o comportamento de bloco. Seu desafio é aplicar as propriedades de exibição corretas no seu CSS para forçar todos os itens da lista a ficarem alinhados lado a lado em uma única linha horizontal, transformando a lista vertical em um menu profissional de cabeçalho.

#### 🔔 Exercício 2: O Botão de Ação com Ícone
Conecte a biblioteca do **Bootstrap Icons** no seu documento HTML. Em seguida, crie um link que simulará um botão de "Baixar Arquivo". Dentro deste link, adicione o texto e um ícone de seta para baixo baseado na classe oficial da documentação.

Ao abrir o navegador, você notará que não consegue dar uma largura e altura confortáveis para esse botão porque a tag de link puro ignora essas propriedades. Modifique o comportamento de exibição deste elemento no CSS de modo que ele passe a aceitar um tamanho fixo em pixels para a largura e altura, mas que ainda permita que outros elementos de texto se posicionem na mesma linha se necessário. Mude também o tamanho e a cor do ícone usando as propriedades de texto apropriadas.

#### 🕵️‍♂️ Exercício 3: O Laboratório de Transformação Direta
Crie três caixas de divisão genéricas simples no seu HTML, cada uma contendo apenas uma palavra curta dentro dela. 

1. No CSS, dê uma cor de fundo diferente para cada uma dessas caixas para conseguir enxergar os limites físicos delas na tela do navegador. Observe como elas ocupam a tela toda de ponta a ponta.
2. Agora, altere cirurgicamente o comportamento de exibição dessas três caixas no seu arquivo de estilos para que elas subam e fiquem posicionadas exatamente uma ao lado da outra, dividindo de forma harmônica a mesma linha da tela. O tamanho do fundo colorido de cada caixa deve passar a corresponder apenas ao espaço exato da palavra que está guardada dentro dela.
