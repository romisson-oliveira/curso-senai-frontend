## 📖 Sobre o Curso

O curso de **Programador Front-End** tem como objetivo capacitar o aluno a desenvolver interfaces web modernas, focando em usabilidade, performance e boas práticas de mercado. O curso é dividido em Unidades Curriculares (UCs) que cobrem desde a lógica inicial até frameworks avançados.

---

## 🗂️ Organização do seu Aprendizado

Para que você consiga acompanhar o curso e encontrar seus códigos facilmente, vamos seguir este padrão de organização de pastas. Isso ajudará você a criar seu portfólio no futuro!

1. **Pasta Principal**: Crie uma pasta com seu nome seguido de `-frontend`.
    - Exemplo: `carlos-frontend`

2. **Unidades Curriculares (UCs)**: Dentro da pasta principal, crie uma pasta para a matéria atual.
    - Exemplo: `uc-02-logica-js`

3. **Pastas por Aula**: Para cada dia de aula, teremos uma pasta específica. Nela você pode salvar seus resumos e anotações.
    - Exemplo: `aula-01`, `aula-02`

4. **Exercícios e Desafios**: Dentro de cada aula, teremos a pasta para o "mão na massa".
    - Exemplo: `exercicios` ou `desafios`

---

#### 🌳 **Estrutura de Pastas (Visualização)**

Assim deve ficar a "árvore" do seu projeto no computador:

```
carlos-frontend/               <-- Seu repositório principal

    ├── aula-01/               <-- Pasta do dia
    │   ├── anotacoes.txt      <-- Suas notas da aula

        └── desafios/

```

## 🚀 Como utilizar este material

1.  **Faltou à aula?** Acesse a pasta da aula correspondente para ler o resumo no `README.md` da subpasta.
2.  **Dúvidas no código?** Compare a sua implementação com os arquivos de exemplo postados aqui.
3.  **Desafios:** As instruções de cada exercício estarão detalhadas nas pasta `exercicios/`.

> **Dica:** Não apenas copie o código. Tente entender a **Lógica** por trás de cada linha. O código é a tradução do seu pensamento!
