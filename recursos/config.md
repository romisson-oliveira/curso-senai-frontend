## ⚙️ Configuração do Workspace

**✅ Tema:** Setup para ferramentas necessárias ao andamento do curso

### 📝 Editor de Código → **Visual Studio Code**

Para poder prosseguir com nossos estudos, vamos utilizar um dos mais famosos editor de códigos: o **VSCODE**.

A instalação é tranquila!

---

#### Extensões recomendadas:

> Para buscar uma extensão: basta digitar o atalho `CRTL+SHIFT+X`. Vai abrir o painel de geranciamento de extensões e pesquise o nome da extensão que desejar.

As extensões são pacotes de instalação de recursos que podemos utilizar no vscode para tornar nosso trabalho mais produtivos. Alguns são para melhorar a estética do código e tornáa-los mais legíveis. Porém, vai do gosto pessoal de cada um. Para encontrar configurações que vocês gostem, basta pesquisar sobre isto no Google e encontrar aquelas que mais lhe agradam.

Segue algumas que eu gosto de utilizar:

- **Prettier - Code formatter**: para deixar o código formatado;
- **Symbols**: para deixar os ícones das pastas e arquivos com design bem limpo e bonito;
- **HackTheBox**: é um tema para deixar o vscode com cores e efeito dark;
- **HTML CSS Support**: para inserir alguns recursos ao seu arquivo `.html` e `.css`;
- **Fluent Icons**: deixar os ícones da lateral esteticamente muito claros e limpos;
- **Markdown Preview Enhanced**: Ao abrir um arquivo do tipo `markdown`, eu digito o atalho `CRTL+SHIFT+V` para abrir um visualizador de markdown como produto final;
- **Auto Rename**: é uma extensão que muda automatimaticamente a tag de fechamento quando você precisa alterá-la;
- **Live Server**: rodar um servidor na sua máquina para poder executar seus arquivos `.html`.

#### VS Code Para Português

_Siga os seguintes passos para deixar seu VS Code em português:_

1. Com seu VS Code aberto, digite o seguinte atalho no teclado:
    - `Ctrl + Shift + p`
2. Vai abrir um `dropdown` para você digitar seu comando. Basta digitar:
    - `Configure Display Language`
3. Clique na opção e escreva:
    - `Português (Brasil)`.
4. Aguarde o VS Code reiniciar e pronto!

> **Atenção**: é super recomendado que mantenha seu VS Code no idioma origial. Assim que tiver um certo domínio, retorne ao padrão. A maioria dos tutoriais e empresas trabalham desta forma.

#### Atalhos VS Code

| Comando           | O que isto faz?                                                    |
| ----------------- | :----------------------------------------------------------------- |
| `Alt + Z`         | Faz o código "quebrar linha" para não precisar de barra de rolagem |
| `Ctrl + Espaço`   | Abre a lista de opções de valores possível (o famoso _Emmet_)      |
| `Shift + Alt + F` | Formata o documento com o formatador padrão do VS Code             |
| `Alt + ↓ ou ↑`    | Faz o texto que está selecionado descer ou subir                   |
| `Ctrl + B`        | Abre ou fecha o explorador de arquivos do VS Code                  |
| `Ctrl + W`        | Fecha a janela que está aberta                                     |
| `Alt + [número]`  | Se você quer ir à janela '2', você troca de aba rapidamente        |
| `Ctrl + TAB`      | Você troca entre as abas rapidamente, acessa à próxima             |
| `Ctrl + S`        | Salva seu documento                                                |
