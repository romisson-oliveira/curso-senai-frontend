## 📚 **Dicionário do Programador Front-End**

**Legenda**

- 🟥 Em `vermelho`: Termos que ainda não exploramos.
- 🟧 Em `laranja`: Termos que ouvimos falar, mas não nos aprofundamos.
- ⬛ Em **Preto**: Termos que já vimos em sala de aula!

| Termo                                                 | Significado                                                                                                                                  |
| :---------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **Front-End**                                         | Lado do cliente. É a parte do site que vemos no navegador, responsável por mostrar o sistema na tela e interagir com o usuário.              |
| **Back-End**                                          | Lado do servidor. É a parte "invisível", responsável por armazenar dados e gerenciar as regras do sistema.                                   |
| <span style="color: orange">**Protocolo HTTP**</span> | _Hypertext Transfer Protocol_: é o "caminho" ou conjunto de regras criado para possibilitar o envio e recebimento de documentos na internet. |
| **WWW**                                               | _World Wide Web_: é a rede mundial de computadores que permite o acesso a páginas e documentos interligados.                                 |
| **URL**                                               | _Uniform Resource Locator_: é o endereço completo e único de um site ou arquivo na internet (a "morada" digital).                            |
| **HTML**                                              | _HyperText Markup Language_: linguagem de marcação usada para criar o **esqueleto** e a estrutura de um site através de etiquetas (tags).    |
| <span style="color: orange">**CSS**</span>            | _Cascading Style Sheets_: linguagem de estilos usada para dar a **aparência** ao site (cores, fontes, alinhamentos).                         |
| <span style="color:orange">**JavaScript**</span>      | Linguagem de programação que adiciona **interatividade** e lógica ao site (cliques, cálculos e animações).                                   |
| **Navegador e menu Inspecionar**                      | O software (Chrome, Edge, etc) que atua como o "tradutor", lendo o código e montando a página visual.                                        |
| **Servidor**                                          | Um computador potente que fica ligado 24h por dia "servindo" os arquivos do site para os navegadores.                                        |
| <span style="color: orange">**DNS**</span>            | _Domain Name System_: É o "catálogo telefônico" da internet. Ele traduz o nome (google.com) no endereço real do servidor (IP).               |
| <span style="color: red">**TCP**</span>               | _Transmission Control Protocol_: Conjunto de regras que garante que os dados cheguem sem erros e na ordem correta.                           |
| <span style="color: red">**Repositório**</span>       | É como uma "pasta inteligente" que registra todo o histórico de alterações de um projeto.                                                    |
| **Extensão de Arquivo**                               | O sufixo (ex: `.html`) que diz ao computador qual programa deve abrir aquele arquivo.                                                        |
| <span style="color: red">**Versionamento**</span>     | Prática de salvar o progresso em etapas, funcionando como uma **máquina do tempo** para o seu código.                                        |
| **Tags HTML**                                         | As etiquetas individuais que usamos para dar ordens ao navegador (ex: `<p>`, `<h1>`).                                                        |
| **Elementos HTML**                                    | O conjunto completo: etiqueta de abertura + conteúdo + etiqueta de fechamento.                                                               |
| <span style="color: red">**Atributo da tag**</span>   | Uma informação extra dentro de uma tag para mudar seu comportamento (ex: o `src` de uma imagem).                                             |
