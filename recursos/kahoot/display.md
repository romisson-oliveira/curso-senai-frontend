## 🟥 Pergunta 1:
Qual é o comportamento padrão de exibição de uma tag `<div>` no CSS?

- 🟥 Vermelho: `inline`
- 🟦 Azul: `block`
- 🟨 Amarelo: `inline-block`
- 🟩 Verde: `none`

✅ **Resposta correta:** 🟦 Azul

---

## 🟥 Pergunta 2:
O que acontece se você aplicar a propriedade `width: 300px` em uma tag `<span>` pura?

- 🟥 Vermelho: Ela fica com 300px de largura imediatamente.
- 🟦 Azul: Ela quebra automaticamente para a linha de baixo.
- 🟨 Amarelo: O navegador ignora a largura, pois ela é um elemento inline.
- 🟩 Verde: Ela desaparece da tela do usuário.

✅ **Resposta correta:** 🟨 Amarelo

---

- 🟦 Azul: `inline`
- 🟨 Amarelo: `inline-block`
- 🟩 Verde: `hidden`

✅ **Resposta correta:** 🟨 Amarelo

## 🟥 Pergunta 4:
Se definirmos apenas a largura (`width`) de uma imagem no CSS, o que acontece com a altura (`height`)?

- 🟥 Vermelho: Fica automaticamente com 0px de altura.
- 🟦 Azul: Fica com o mesmo valor exato que foi definido para a largura.
- 🟨 Amarelo: O navegador calcula a altura automaticamente (`auto`), mantendo a proporção.
- 🟩 Verde: A imagem quebra e fica totalmente distorcida na tela.

✅ **Resposta correta:** 🟨 Amarelo

Qual das seguintes tags possui o comportamento inline por padrão no HTML?

- 🟥 Vermelho: `<p>`

## 🟥 Pergunta 6:
O que a configuração `display: block` faz com um elemento na tela?

- 🟥 Vermelho: Ocupa 100% da largura disponível e empurra o próximo elemento para baixo.
- 🟦 Azul: Ocupa apenas o espaço do texto e permite vizinhos na mesma linha.
- 🟨 Amarelo: Deixa o elemento invisível na página, mas mantém o espaço dele.
- 🟩 Verde: Bloqueia o elemento para que o usuário não consiga clicar nele.

✅ **Resposta correta:** 🟥 Vermelho

---

## 🟥 Pergunta 7:
Qual é a diferença crucial entre aplicar `display: none` e deixar um elemento invisível?

- 🟥 Vermelho: Nenhuma, ambas as formas agem exatamente do mesmo jeito.
- 🟦 Azul: O `display: none` faz o elemento sumir e os outros elementos ocupam o espaço dele.
- 🟨 Amarelo: O `display: none` mantém o espaço em branco do elemento guardado na tela.
- 🟩 Verde: O `display: none` só funciona se for aplicado em tags de imagem.

✅ **Resposta correta:** 🟦 Azul

## 🟥 Pergunta 9:
Por que a unidade de medida Pixel (`px`) é classificada como uma unidade Absoluta?

- 🟥 Vermelho: Porque ela muda de tamanho dependendo do tamanho do elemento pai.
- 🟦 Azul: Porque ela tem um valor fixo baseado nos pontos físicos de luz da tela.
- 🟨 Amarelo: Porque ela se adapta automaticamente quando abrimos o site no celular.
- 🟩 Verde: Porque ela só pode ser utilizada para medir tamanhos de textos.

✅ **Resposta correta:** 🟦 Azul

## 🟥 Pergunta 14:
Para criar um botão a partir de um link (`<a>`) com tamanho exato de `150px` por `50px`, o que devemos fazer?

- 🟥 Vermelho: Alterar o `display` do link para `block` ou `inline-block`.
- 🟦 Azul: Apenas colocar os pixels, pois a tag `<a>` já aceita tamanhos por padrão.
- 🟨 Amarelo: Mudar o `display` do link obrigatoriamente para `inline`.
- 🟩 Verde: Colocar o valor de tamanho dentro do atributo `id` da tag HTML.

✅ **Resposta correta:** 🟥 Vermelho

## 🟥 Pergunta 15:
Se aplicarmos `display: inline-block` em três `divs` seguidas, como elas se posicionarão na tela?

- 🟥 Vermelho: Continuarão empilhadas uma embaixo da outra.
- 🟦 Azul: Sumirão da tela completamente, limpando o layout.
- 🟨 Amarelo: Ficarão organizadas uma ao lado da outra na mesma linha.
- 🟩 Verde: Ficarão sobrepostas (uma exatamente em cima da outra).

✅ **Resposta correta:** 🟨 Amarelo
