## 📚 Aula 01: UC-02 - Lógica de Programação

**✅ Tema:** Conceitos iniciais e entendimento do conceito cliente-servidor

---

### 🧠 O que vimos hoje?

- **Lógica de Programação:** A técnica de organizar o pensamento de forma estruturada para atingir um objetivo específico.
- **Algoritmo:** A "receita" com a sequência lógica de passos para cumprir uma tarefa muito bem definida.
- **Modelo IPO (Input, Process, Output):** A base da estruturação de sistemas. Entender quais são os dados de _entrada_ (o que recebemos), o que faremos com estes dados (_processamento_) e qual resultado esperado (_qual saída devemos retornar_).
- **Dado x Informação:** A diferença fundamental entre dados brutos e informações processadas.
- **Arquitetura Cliente-Servidor:** O entendimento básico de como funciona a comunicação e a troca de dados através da internet.
