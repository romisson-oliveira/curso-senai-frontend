## 📚 Aula 02: UC-02 - Lógica de Programação

**✅ Tema:** Introdução ao conceito de variáveis e tipos de dados

---

### 🧠 O que vimos hoje?

- **O que são variáveis?**: como um recurso utilizado pelas linguagens de programação para reservar um espaço em memória para guardar dados;
- **Tipo Primitivos de Dados**: vimos apenas dois dos principais tipos primitivos de dados em Javascript: `string` e `number`. Cada linguagem tem sua forma de identificar e lidar com os tipos de dados;
- **Declaração de variáveis e atribuição**: vimos como declarar variáveis em Javascript (`var`, `let` e `const`) e suas principais diferenças. Vimos, também, como atribuir um dado para dentro desta variável com o sinal de `Assignment` ( `=` );
- **Identificadores de variáveis**: vimos como nomear estes espaços para resgatar o dado guardado apenas "chamando" este identificador. Regras de sintaxe que o Javascript exige para nomear _suas_ variáveis.
