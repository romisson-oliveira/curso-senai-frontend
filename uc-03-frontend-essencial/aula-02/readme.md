## 📚 Aula 02: UC-03 - Front End Essencial

**✅ Tema:** Praticar marcação de parágrafos e títulos.

---

### 🧠 O que vimos hoje?

- Tag `p` para marcação de títulos;
- Hierarquia de título e suas tags:

```
<h1>Título 1</h1>
<h2>Título 2</h2>
<h3>Título 3<h3>
<h4>Título 4</h4>
<h5>Título 5</h5>
<h6>Título 6</h6>
```

- Sugestão usar apenas uma tag de h1 por página;
- As tags sendo para dar sentido ao navegador sobre o que representa um texto, portanto ao utilizar uma tag de `h1`, por exemplo, indicamos que o texto inserido neste elemento html representa o **título principal** da página.
