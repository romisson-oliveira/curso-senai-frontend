**✅ Tema:** Listas ordenadas e listas não ordenadas

---

### 🧠 O que vimos hoje?

- Para criar um lista ordenada ou não ordenada, precisamos indicar para o navegador que teremos uma. Como sabemos, utilizamos, em html, o recurso de **tags**.

#### Lista Ordenada (`<ol>` - Ordered List):

Utilizada quando a sequência dos itens é importante, como em um passo a passo.

- Tag: `<ol>`
- Exemplo:

```
<ol>
  <li>Primeiro passo</li>
  <li>Segundo passo</li>
  <li>Terceiro passo</li>
</ol>

```

#### Lista Não Ordenada (`<ul>` - Unordered List):

Utilizada para itens que podem ser listados em qualquer ordem, como uma lista de compras.

- Tag: `<ul>`
- Exemplo:

```
<ul>
  <li>Item A</li>
  <li>Item B</li>
  <li>Item C</li>
</ul>

```

#### Itens da Lista (`<li>` - List Item):

Tanto as listas ordenadas quanto as não ordenadas usam a tag `<li>` para definir os itens que compõem a lista

- Tag: `<li>`
